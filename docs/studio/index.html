say-my-name / studio

Record your name

Record, trim, download, paste. Everything happens in this tab — the audio never leaves your device, there is no account, and there is no server to upload to.

1 · Your name

Used to build the snippet. Upload the files there yourself.

2 · Pronunciations

Add more than one if your name has a native pronunciation and a local one. Both are correct, and the widget will offer both.

3 · Preview

This is the real component, running on what you just recorded.

4 · Copy the snippet

The snippet assumes the component is already on the page:
<script type="module" src="https://cdn.jsdelivr.net/npm/say-my-name@0"></script>
